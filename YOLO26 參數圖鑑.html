01 / INTRODUCTION

YOLO26 介紹

官網 › models/yolo26

YOLO26 是 Ultralytics 於 2026 年 1 月正式釋出的模型家族，主打邊緣裝置部署。官方表示 YOLO26n 相較 YOLO11n，CPU ONNX 推論最多快約 43%。

原生端到端、免 NMS

內建 One-to-One 偵測頭，推論時加 nms=False 直接輸出結果，不必再做 NMS 後處理。

移除 DFL

拿掉 Distribution Focal Loss，偵測頭更輕，匯出 ONNX、TensorRT 等格式更單純。

新訓練配方

MuSGD（SGD＋Muon 混合最佳化器）、ProgLoss（漸進式損失）、STAL（小目標感知標籤分配）。

七種任務

偵測、實例分割、語意分割、深度估計、分類、姿態、OBB；另有開放詞彙版 YOLOE-26。

train.py
from ultralytics import YOLO

if __name__ == "__main__":          # Windows 多執行緒必要的保護
    model = YOLO("yolo26n.pt")

    model.train(
        data="coco8.yaml",          # 換成自己的資料集 YAML
        epochs=50,
        imgsz=640,
        batch=16,                   # 記憶體不夠改 8，或 -1 自動
        device=0,                   # 沒有 GPU 改 "cpu"
        workers=4,
        patience=20,
        optimizer="auto",           # 或 "MuSGD" / "AdamW"
        project="runs_class",
        name="yolo26n_demo",
    )

    metrics = model.val()
    print("mAP50-95:", metrics.box.map)
    print("mAP50   :", metrics.box.map50)
    # 最佳權重：runs_class/yolo26n_demo/weights/best.pt

from ultralytics import YOLO

model = YOLO("yolo26n.pt")
results = model.predict(
    source="https://ultralytics.com/images/bus.jpg",
    conf=0.4,
    iou=0.5,
    imgsz=640,
    classes=[0, 5],   # 只要 person、bus

    nms=False,        # YOLO26 免 NMS

    save_txt=True,

import cv2
from ultralytics import YOLO

model = YOLO("yolo26n.pt")
cap = cv2.VideoCapture(0)

while cap.isOpened():
    ok, frame = cap.read()
    if not ok:
        break
    r = model(frame, conf=0.4, verbose=False)
    cv2.imshow("YOLO26", r[0].plot())
    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

parse_results.py
from collections import Counter
from ultralytics import YOLO

model = YOLO("yolo26n.pt")
results = model("https://ultralytics.com/images/bus.jpg", conf=0.3)

r = results[0]
print("原圖尺寸：", r.orig_shape)
print("耗時(ms)：", r.speed)
print("偵測數量：", len(r.boxes))

for box in r.boxes:
    name = r.names[int(box.cls[0])]
    conf = float(box.conf[0])
    x1, y1, x2, y2 = box.xyxy[0].tolist()
    print(f"{name:<10} {conf:.2f}  ({x1:.0f},{y1:.0f})-({x2:.0f},{y2:.0f})")

print(Counter(r.names[int(c)] for c in r.boxes.cls))   # 各類別數量

img = r.plot()                      # numpy 影像
r.save(filename="bus_result.jpg")   # 存圖
print(r.to_json())                  # JSON
print(r.to_df())                    # DataFrame
r.save_crop(save_dir="crops")       # 裁切物件
06 / COLAB STREAM

Colab 上推論 YouTube 串流並顯示畫面

官網 › predict#inference-sources

Colab 沒有 OpenCV 視窗，cv2.imshow() 不能用。做法是先建立一個可更新的輸出位置，每推論完一幀，就把畫好框的影像轉成 JPG，換掉上一張，畫面就會像影片一樣播放。

colab_youtube_stream.py
import cv2
import logging
from IPython.display import display, Image
from ultralytics import YOLO

logging.getLogger("ultralytics").setLevel(logging.ERROR)   # 隱藏 WARNING，只顯示真正的錯誤

model = YOLO("yolo26n.pt")
url = "https://www.youtube.com/watch?v=影片或直播ID"

handle = display(display_id=True)        # 建立一個可更新的輸出位置
try:
    for i, r in enumerate(model.predict(url, stream=True, conf=0.4,
                                        vid_stride=2, verbose=False)):
        ok, jpg = cv2.imencode(".jpg", r.plot())
        handle.update(Image(data=jpg.tobytes()))
        if i >= 300:                     # 直播不會結束，設定幀數上限
            break
except KeyboardInterrupt:
    print("已停止")

Waiting for stream 0 是什麼

這不是錯誤。Ultralytics 用另一條執行緒讀串流，推論比畫面送來得快時，就會印出這行表示「下一幀還沒到」。verbose=False 擋不掉，要靠 logging 把等級調到 ERROR。

設定位置不能放錯

setLevel 要寫在 from ultralytics import YOLO 之後。Ultralytics 在 import 時會重設訊息等級，放在前面會被蓋掉。

影響範圍

會隱藏 Ultralytics 所有的 WARNING，真正的錯誤（ERROR）還是會顯示。想看回警告，把 logging.ERROR 改成 logging.INFO。

結束與流暢度

按儲存格左邊的停止鈕即可結束。每一幀都要從 Colab 傳回瀏覽器，通常每秒只有幾幀，適合示範；vid_stride 調大可跳過更多幀。

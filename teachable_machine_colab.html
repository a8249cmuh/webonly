CHAPTER 01

如何在 Teachable Machine 訓練貓狗分類模型

不需編寫任何程式碼，透過瀏覽器在 3 分鐘內完成遷移式學習（Transfer Learning）影像分類訓練。

開啟 Teachable Machine
步驟 1：建立專案与類別 📁

準備「貓」與「狗」資料集

  • • 進入官網選擇 「圖片專案 (Image Project)」 ➔ 「標準圖片模型 (Standard image model)」。
  • • 將 Class 1 改名為 Cat (貓)，點擊「上傳」放入約 20~50 張不同角度的貓咪照片。
  • • 將 Class 2 改名為 Dog (狗)，點擊「上傳」放入約 20~50 張狗狗照片。
步驟 2：訓練超參數設定 ⚙️

點擊「訓練模型 (Train Model)」

  • • 週期數 (Epochs)：預設 50（代表模型把所有貓狗圖片完整看過 50 遍）。
  • • 批次大小 (Batch Size)：預設 16（每次更新權重所參考的圖片數量）。
  • • 學習率 (Learning Rate)：0.001（控制模型修正錯誤的步伐大小）。
步驟 3：即時預覽與進階分析 📊

測試模型與查看「內部細節」

  • • 訓練完成後，右側可切換為 「檔案 (File)」 上傳一張沒看過的貓狗圖測試信心度。
  • • 點擊訓練面板下方的 「深入了解 (Under the hood)」，即可看到如您截圖一的評估圖表！

CHAPTER 02

導出模型介紹 & 為什麼官方範例在目前 Colab 無法直接運行？

對照您提供的第二張截圖，深入剖析導出格式與 Keras 2 / Keras 3 的版本相容性問題。

1. 點擊「導出模型 (Export Model)」

在預覽視窗上方點擊導出按鈕，會出現三個分頁：
• Tensorflow.js：供網頁前端 JS 使用。
• Tensorflow (Keras)：供 Python / Colab 使用（請選這個）。
• Tensorflow Lite：供手機 App 或樹莓派使用。

2. 下載 converted_keras.zip

選擇 Tensorflow ➔ Keras 並點擊下載模型後，解壓縮會得到兩個核心檔案：
• keras_Model.h5：訓練好的模型架構與權重。
• labels.txt：類別標籤（例如 0 Cat、1 Dog）。

3. 複製官方程式碼貼到 Colab 卻報錯！

如果您直接把截圖二中的程式碼貼到目前的 Google Colab 執行，會立即遇到 ValueError: Unrecognized keyword arguments passed to DepthwiseConv2D: {'groups': 1} 等錯誤！

SVG 互動診斷：3 個導致官方範例在 Colab 失效的原因

問題一：DepthwiseConv2D(groups=1) Teachable Machine 導出的 `.h5` 檔內部包含 `"groups": 1` 屬性。在新版 Keras 中，載入模型時會直接拋出 ValueError: Unrecognized keyword arguments: {'groups': 1}。
問題二：expects 1 input(s), but received 2 在最新 Python 3.13 + Keras 3 環境下，載入 Teachable Machine 的巢狀模型（MobileNet 串接分類層）會發生 Layer "functional" expects 1 input(s), but it received 2 input tensors 錯誤。必須改用 tf_keras 載入才能正確解析舊版拓撲結構！
問題三：<IMAGE_PATH> 未替換 官方範例寫著 Image.open("<IMAGE_PATH>")，新手常不知如何把電腦裡的貓狗照片傳進 Colab。我們在下一章的程式碼中直接整合了 google.colab.files 互動上傳按鈕！

colab_teachable_machine_inference.py
支援最新 Colab (Python 3.13 / 解決 2 input tensors 與 groups=1 錯誤) 
# ==============================================================================
# Teachable Machine 貓狗分類模型 - Google Colab 直接運行修復版 (Python 3.13 適用)
# 徹底解決：
# 1. Layer "functional" expects 1 input(s), but it received 2 input tensors
# 2. DepthwiseConv2D Unrecognized keyword arguments: {'groups': 1}
# ==============================================================================

# 安裝 Google 官方 Legacy Keras (tf_keras) 套件，免重啟即可直接匯入使用
!pip install -q tf_keras

import os
import numpy as np
import tf_keras as keras
from PIL import Image, ImageOps
import matplotlib.pyplot as plt
from google.colab import files

# 關閉科學記號顯示，讓機率輸出更清晰
np.set_printoptions(suppress=True)

MODEL_PATH = "keras_Model.h5"
LABELS_PATH = "labels.txt"

# 1. 檢查是否已上傳模型與標籤檔，若無則提示上傳
if not os.path.exists(MODEL_PATH) or not os.path.exists(LABELS_PATH):
    print("📤 請上傳從 Teachable Machine 導出解壓縮後的『keras_Model.h5』與『labels.txt』：")
    uploaded_model = files.upload()

# 2. 定義相容層包裝器：自動過濾掉舊版 Teachable Machine 多餘的 'groups': 1 參數
class CompatibleDepthwiseConv2D(keras.layers.DepthwiseConv2D):
    def __init__(self, *args, **kwargs):
        kwargs.pop("groups", None)
        super().__init__(*args, **kwargs)

# 3. 使用 tf_keras (Keras 2 核心) 載入模型，避免 Keras 3 的 2 input tensors 結構誤判
print("⏳ 正在載入模型...")
model = keras.models.load_model(
    MODEL_PATH,
    custom_objects={"DepthwiseConv2D": CompatibleDepthwiseConv2D},
    compile=False
)

with open(LABELS_PATH, "r", encoding="utf-8") as f:
    class_names = [line.strip() for line in f.readlines()]
print(f"✅ 模型載入成功！偵測到的類別：{class_names}\n")

# 4. 上傳要測試的貓狗圖片並進行推論
print("🖼️ 請選擇一張或多張要測試的「貓 / 狗」圖片上傳：")
uploaded_images = files.upload()

for img_name in uploaded_images.keys():
    # 建立符合模型輸入格式的陣列 (1, 224, 224, 3)
    data = np.ndarray(shape=(1, 224, 224, 3), dtype=np.float32)

    # 讀取圖片並轉換為 RGB
    image = Image.open(img_name).convert("RGB")

    # 調整大小並從中心裁切為 224x224 (Teachable Machine 標準前處理)
    size = (224, 224)
    image_resized = ImageOps.fit(image, size, Image.Resampling.LANCZOS)

    # 轉為 numpy 陣列並正規化至 [-1, 1] 區間
    image_array = np.asarray(image_resized)
    normalized_image_array = (image_array.astype(np.float32) / 127.5) - 1
    data[0] = normalized_image_array

    # 執行預測
    prediction = model.predict(data, verbose=0)
    index = np.argmax(prediction)
    class_name = class_names[index]
    confidence_score = prediction[0][index]

    # 去除標籤前面的數字編號 (例如 "0 Cat" -> "Cat")
    clean_label = class_name.split(" ", 1)[1] if " " in class_name else class_name

    # 印出結果與繪製圖片
    print("=" * 45)
    print(f"📄 檔案名稱：{img_name}")
    print(f"🎯 預測類別：{clean_label} (原始標籤: {class_name})")
    print(f"📊 信心指數：{confidence_score * 100:.2f}%")
    print("=" * 45)

    plt.figure(figsize=(4, 4))
    plt.imshow(image_resized)
    plt.title(f"Prediction: {clean_label} ({confidence_score*100:.1f}%)", fontsize=12, fontweight="bold")
    plt.axis("off")
    plt.show()

# ==============================================================================
# Teachable Machine 貓狗分類模型 - Gradio 互動式網頁應用 (Colab Python 3.13 完美運行版)
# ==============================================================================

# 1. 自動安裝 Gradio 與 tf_keras (解決 Keras 3 載入舊版 H5 的 2 input tensors 錯誤)
!pip install -q gradio tf_keras

import os
import numpy as np
import tf_keras as keras
import gradio as gr
from PIL import Image, ImageOps
from google.colab import files

np.set_printoptions(suppress=True)

MODEL_PATH = "keras_Model.h5"
LABELS_PATH = "labels.txt"

# 2. 檢查模型與標籤檔案是否存在，若不存在則提示上傳
if not os.path.exists(MODEL_PATH) or not os.path.exists(LABELS_PATH):
    print("📤 請先上傳『keras_Model.h5』與『labels.txt』：")
    files.upload()

# 3. 定義 DepthwiseConv2D 相容層，忽略舊版 'groups': 1 參數
class CompatibleDepthwiseConv2D(keras.layers.DepthwiseConv2D):
    def __init__(self, *args, **kwargs):
        kwargs.pop("groups", None)
        super().__init__(*args, **kwargs)

# 4. 使用 tf_keras 載入模型與類別名稱
print("⏳ 正在載入模型...")
model = keras.models.load_model(
    MODEL_PATH,
    custom_objects={"DepthwiseConv2D": CompatibleDepthwiseConv2D},
    compile=False
)

with open(LABELS_PATH, "r", encoding="utf-8") as f:
    raw_labels = [line.strip() for line in f.readlines()]
    # 將 "0 Cat" 格式化為乾淨的類別名稱 "Cat"
    class_names = [label.split(" ", 1)[1] if " " in label else label for label in raw_labels]
print(f"✅ 模型載入完成！類別：{class_names}")

# 5. 定義 Gradio 影像預測函數
def classify_image(image):
    if image is None:
        return None

    # 確保為 PIL RGB 影像
    image = image.convert("RGB")

    # 中心裁切並縮放至 224x224
    size = (224, 224)
    image = ImageOps.fit(image, size, Image.Resampling.LANCZOS)

    # 轉換為陣列並正規化至 [-1, 1]
    image_array = np.asarray(image)
    normalized_image_array = (image_array.astype(np.float32) / 127.5) - 1

    data = np.ndarray(shape=(1, 224, 224, 3), dtype=np.float32)
    data[0] = normalized_image_array

    # 模型推論
    prediction = model.predict(data, verbose=0)[0]

    # 回傳字典格式 {類別名稱: 機率浮點數} 供 Gradio Label 元件繪製排行榜
    return {class_names[i]: float(prediction[i]) for i in range(len(class_names))}

# 6. 建立並啟動 Gradio 互動介面
demo = gr.Interface(
    fn=classify_image,
    inputs=gr.Image(type="pil", label="上傳或拖曳貓/狗照片"),
    outputs=gr.Label(num_top_classes=len(class_names), label="AI 預測結果與信心度"),
    title="🐾 Teachable Machine 貓狗影像分類器",
    description="上傳一張貓咪或狗狗的照片，模型將會即時分析並顯示各類別的預測機率！"
)

# share=True 會在 Colab 產生一個公開的 .gradio.live 網址，手機也能點開測試！
demo.launch(share=True, debug=False)

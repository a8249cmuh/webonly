1. 正確率 (Accuracy)

95.0%
公式：(TP + TN) / (TP + TN + FP + FN) 950 / 1000

白話意義：在所有樣本中，模型到底猜對了多少比例？

2. 精確率 (Precision / 查準率)

72.7%
公式：TP / (TP + FP) 80 / (80 + 30)

白話意義：凡是模型說「是」的，有多少是真的？（看重不誤報）。

3. 召回率 (Recall / 查全率)

80.0%
公式：TP / (TP + FN) 80 / (80 + 20)

白話意義：在所有真實有病的患者中，抓出了多少？（看重不漏抓）。

4. F1 值 (F1-Score / 調和平均)

76.2%
公式：2 × (Precision × Recall) / (Precision + Recall) 2×(P×R)/(P+R)

白話意義：精確率與召回率的調和平均數，專門避免只偏廢某一邊。

🎯 各指標實務「適用地點 / 業務場景」完整解密

為什麼機器學習實務上不能只看 Accuracy？關鍵在於「錯報的成本」與「漏報的代價」哪一個更嚴重！

正確率 (Accuracy) 總體正確
🏢 適用地點 / 業務場景：
  • 類別比例相當的分類任務
  • 手寫數字識別 (MNIST 0~9 比例各 10%)
  • 一般情感分析 (正面/負面各佔 50%)
  • 動植物物種影像二分法
⚠️ 致命盲點 (準確率陷阱)：

當資料極不平衡時（如 99% 健康、1% 罹癌），模型就算全部猜健康，Accuracy 也能高達 99%，但病人全死光，此指標完全失真！

精確率 (Precision) 不能冤枉好人
🏢 適用地點 / 業務場景：
  • 誤報成本極高的業務地點
  • 垃圾郵件過濾（絕不能把重要合約信誤判成垃圾郵件丟掉）
  • 刷臉解鎖 / 門禁支付（絕不能讓路人解鎖你手機）
  • 精準推薦系統（YouTube 推薦用戶真正想看的）
🎯 核心哲學：

「寧可少抓，絕不亂抓」。只要我舉手說你是正例，我就必須有極高把握！

召回率 (Recall) 不能放走壞人
🏢 適用地點 / 業務場景：
  • 漏報代價致命的監控地點
  • 癌症惡性腫瘤篩檢（寧可誤報進一步檢查，絕不能漏診）
  • 金融信用卡盜刷 / 詐欺監控
  • 地震 / 海嘯早期預警系統
  • 機場安檢违禁品 X 光掃描
🎯 核心哲學：

「寧可錯殺一百，絕不放過一人」。真實有危險的對象，我必須百分之百全部揪出來！

F1-Score 綜合黃金指標
🏢 適用地點 / 業務場景：
  • 類別不均衡且 Precision 與 Recall 均不可偏廢時
  • Google 搜尋引擎檢索排序 (資訊檢索 IR)
  • 自然語言處理：命名實體識別 (NER)
  • 罕見瑕疵零件檢測（智慧工廠 AOI 檢驗）
🎯 核心哲學：

調和平均數的特性是：只要其中一個指標非常低（例如 Precision=99% 但 Recall=1%），F1 值就會被嚴厲拉低，防止自欺欺人。

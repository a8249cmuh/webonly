JSON 從哪裡來？

JSON 是一種「用純文字記錄資料」的格式。它小巧、人看得懂、程式也好讀寫，所以成為今天網路上交換資料最常用的格式。

名字拆解

滑過字母看看

發音和英文名字 Jason 一樣。名字裡雖然有 JavaScript，但 Python、Java、C#、PHP… 幾乎所有程式語言都能讀寫 JSON，它是跨語言的資料格式。

今天在哪裡會遇到 JSON？

  • 🌐
    Web API天氣、地圖、YouTube 等服務回傳的資料，幾乎都是 JSON。
  • ⚙️
    設定檔VS Code 的 settings.json、Node.js 專案的 package.json。
  • 📓
    Colab／Jupyter 筆記本.ipynb 檔案打開來看，其實就是一份 JSON。
  • 🖼️
    影像標註COCO 格式的物件偵測標註檔，用 JSON 記錄框的位置與類別。
  • 🤖
    AI 應用呼叫大型語言模型 API 時，送出的請求和收到的回應都是 JSON。

    PART 1 · 第 2 章
    
語法規則：只要記住這幾條

    
JSON 的規則非常少，但也非常嚴格，多一個逗號、少一個引號，整份資料就無法讀取。

  

  

    
1
資料以「鍵: 值」配對
每一筆資料都有名字（鍵）和內容（值），中間用冒號隔開。
"name": "王小明"

    
2
鍵一定要加雙引號
鍵必須是字串，而且只能用半形雙引號 "，不能用單引號。
"age" ✅   age ❌   'age' ❌

    
3
用逗號分隔，最後一個不加
成員之間用 , 分隔，最後一個成員後面不能有逗號。
[1, 2, 3] ✅   [1, 2, 3,] ❌

    
4
物件 { }、陣列 [ ]
大括號包「鍵值對」，中括號包「有順序的值」，括號一定要成對。
{ "a": [1, 2] }

    
5
只有 6 種型態
字串、數字、布林、null、物件、陣列。沒有日期、沒有函式、沒有 undefined。
true / null 全小寫

    
6
不能寫註解
JSON 刻意不支援 // 或 /* */ 註解。檔案用 UTF-8 編碼、副檔名 .json。
MIME：application/json

陣列 Array：一排有順序的值

    
陣列用中括號 [ ] 包起來，值之間用逗號分隔。每個位置有一個索引（index），而且是從 0 開始數！

  

  

    

      

        
        
      

      
      
      
      
    

    
    

      選擇索引
      
      0
    

    

    
目前的 JSON

  

  

    
0
索引從 0 開始
第 1 個元素是 [0]，最後一個是 [長度 - 1]。超過範圍就取不到值。

    
⧉
可以放任何型態
[1, "二", true, null] 合法，但實務上建議同一個陣列放同一種東西。

    
▦
陣列裡可以再放陣列
二維陣列 [[1, 2], [3, 4]]，取 3 要寫 matrix[1][0]。

  







  

    PART 1 · 第 6 章
    
標點符號：JSON 的骨架

    
整個 JSON 只靠 8 個符號撐起結構：{ } [ ] : , "（加上跳脫用的 \）。看懂它們，就能讀懂任何 JSON。

  

  

    
符號圖鑑
點符號，右側範例會同步亮起

    
    

      

      

    

  

  

    
⚠️ 全形符號陷阱
用中文輸入法打字時，最容易不小心打出全形符號。它們看起來很像，但 JSON 完全不認得！

    

    

      
用途✅ 半形（正確）❌ 全形（錯誤）小提醒

      
冒號:：全形冒號比較寬，後面像多了空白

      
逗號,，最常見的錯誤之一

      
引號" "“ ” 「 」Word、簡報會自動把 " 變成彎引號

      
括號{ } [ ]｛ ｝ ［ ］打括號前先切換成英文輸入

    

    

    
小技巧：到 Playground 貼上你的 JSON，驗證器會直接指出是哪個全形符號出錯。
